# MindSense — Mental Health Prediction

A full-stack machine learning application that predicts a **mental health score** based on digital habits, lifestyle, academic routine, and demographic information.

> **Disclaimer:** This project is for educational and research purposes only. It is not a medical diagnostic tool and should not replace professional medical advice.

## Tech Stack

### Frontend

* Next.js
* TypeScript
* Tailwind CSS
* Framer Motion
* React Hook Form
* Zod

### Backend

* FastAPI
* Python
* Pydantic
* Pandas
* Joblib

### Machine Learning

* Trained machine learning model
* Model stored as `Mental_Health_Model.pkl`

## How It Works

```text
User Input
    ↓
Next.js Frontend
    ↓
FastAPI /predict API
    ↓
Machine Learning Model
    ↓
Predicted Mental Health Score
    ↓
Result Display
```

The application collects information such as:

* Age, gender, and country
* Academic level
* Most-used social media platform
* Purpose of social media use
* Daily social media usage
* Daily phone unlocks
* Study hours
* Physical activity
* Sleep duration
* Stress level

The backend validates the input using **Pydantic**, prepares the data using **Pandas**, and sends it to the trained model to generate a predicted score.

## Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
cd ml-predict
```

### 2. Run the Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

The API will run at:

```text
http://localhost:8000
```

### 3. Run the Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

The frontend will run at:

```text
http://localhost:3000
```

## API

### `GET /`

Returns a welcome message.

### `POST /predict`

Accepts the user's assessment data and returns the predicted mental health score.

Example response:

```json
{
  "predicted_mental_health_score": 6.42
}
```

## Disclaimer

The prediction is generated by a machine learning model and should **not be interpreted as a clinical diagnosis or medical assessment**. Results may vary depending on the quality and limitations of the training data.
